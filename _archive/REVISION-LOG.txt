AIU TOTEM - REVISION LOG
========================
Nothing is ever deleted for good. When something leaves the app it lands here, in _archive,
with a note on what it was and how to bring it back.


1.1.0  (October 8, 2026)  "the big reorganize"
-----------------------------------------------
Why: 1.0.5 felt crowded. Too much scrolling, four tabs that didn't match how the app gets used,
chat lines you couldn't fix, and voice bugs (repeating itself, voice changes not sticking).

KNOWN LIMITS / POINTS OF FAILURE (1.1.0)
  - Accounts: the cards are only as safe as your Aiu password. A device keeps the key (not the
    password) in its browser storage; anyone who can unlock your phone and open Aiu can read
    them. Forgot the password and no device still opens the cards = they stay locked.
  - Changing the password on one device: the others ask for the new password once.
  - Fixing a misheard line fixes the line and Aiu answers again, but anything Aiu already filed
    from the old words (a topic answer, a list item) stays as it was: fix those where they live.
  - GABA notices only things you say you DID ("I went for a walk", "had an energy drink"), not
    plans. It can still guess wrong; delete any line in Library > GABA > Today's log.
  - Monthly and yearly planner items don't pop up as reminders (the reminder system only does
    once / daily / weekdays / weekends / some weekdays). Aiu mentions bills due in the next 3 days
    in its greeting once a day, and the Agenda lists them.
  - PDFs use the PDF viewer's built-in font, so emoji and non-Latin letters are dropped.
  - iPhone home-screen app: the PDF opens in a preview; use Share > Save to Files or Print.
  - Big business documents: each section holds up to 15,000 characters (the server limits one
    event to 16 KB). Split very long sections in two.

2.6.0 CLOSING THE LOOPS: INVITES, ADMIN, RECOVERY CODE, LOCKED CAPSULES; ALLOWANCE AND GOOD STARS (October 15, 2026)
------------------------------------------------------------------------------------------------------------------
  Safety
  - Sign-up needs the invite code (INVITE_CODE in api.php/api.cgi, AIU_INVITE_CODE; the README has it).
  - Admin recovery: action 'admin_recover' (admin user + password, checked against ADMIN_SALT/ADMIN_HASH; the plain
    password is only in the README) sets a temporary password for an account and logs out its devices. Logged to
    aiu_data/admin.log; rate-limited. The app: Log in > Forgot your password? > I'm the admin.
  - Recovery code (vault.js newCode/wrapRescue/openRescue/codeOf; app.js rescueMake/rescueUse; setting
    'vaultRescue'): a 16-character code wraps the card key; the code itself is kept sealed by the card key, so a
    password change re-wraps the same code (vaultRekey). Accounts > Cards > Lost your password? opens everything
    with the code + the current password, then re-locks it all to that password.
  - Locked capsules (.aiucap): "AIUCAP1\n" + salt + iv + the zip under AES-GCM (PBKDF2 200,000 from the capsule
    password). On by default; unlocked needs a confirm. Every export path goes through it.
  - Dev tools only with config.js devtools: true; the server drops 'dev_growth' unless AIU_ALLOW_DEV=1; test growth
    and imported (imp) events never make tokens; imported 'tbuy' doesn't spend.
  - Files: 250 MB per account, 5000 MB per server (507 server_full). blob_list + F.tidy (weekly): server files
    nothing points to are removed after a week; a file this device holds that never reached the server goes up again.
  - shop.js watchBuys: a purchase that came up short when it synced says so (and takes the item off).
  Economy (core VERSION 12)
  - 'allow' events: 10 a day (+25 the first day of each week, by its Monday), at most once a day; the day must be
    within a week before the server's receive day (offline days still count; a moved clock can't add any).
  - Good Stars (S.stars {lv, last}, starsTo): a day with 10+ growth steps up, a day without steps down; earned
    tokens x C.STAR_MULT[lv] (1 to 2), at most 60 a day (S.tokEarn).
  - 'tspend' events: treats (fireworks and confetti drawn by shop.js drawFx over World; the fancy snack fills the
    pet). The Corner Mart: This week (4 of 10 specials, seeded by the Monday), Treats, Pet gear (free collar,
    saddle, no gear; backpack 35).
  - The old server-folder shop is retired (_archive/2.6.0-replaced/app.old-shop-1.0.5.js).
